# 爆音日记 BASS DIARY —— 新粗野主义个人博客示例

一个**单文件自包含**的个人博客示例(HTML + 内嵌 CSS/JS,零依赖、零网络请求),
风格:新粗野主义 (Neo-Brutalism) × 90 年代个人主页气质。

## 打开方式

直接双击 `index.html` 即可,无需服务器、无需构建。

## 设计系统

所有视觉参数集中在 `index.html` 顶部的 `:root` CSS 变量中,换肤只改一处:

| 变量 | 值 | 用途 |
|---|---|---|
| `--ink` | `#161616` | 主墨色:边框与文字 |
| `--paper` | `#fffbf0` | 米白纸底 |
| `--yellow` / `--blue` / `--pink` / `--lime` / `--orange` / `--purple` | — | 高饱和撞色板 |
| `--bd` | `3px solid` | 标准粗边框 |
| `--shadow` | `6px 6px 0` | 硬阴影(零模糊,方向恒为右下) |

## 功能清单

- 顶栏跑马灯(纯 CSS 无限滚动)
- 头图:超大衬线标题 + 分层硬阴影 + 旋转贴纸
- 文章卡片网格 → 点击打开阅读弹层(支持 Esc / 点击空白关闭)
- 本地访客计数器(localStorage,倒计时动画)
- 按时段变化的问候语
- 方形滚动条、星光光标、`prefers-reduced-motion` 降级

## 如何加一篇文章

1. 在 `.posts` 里复制一张 `.post-card`,改标题/摘要/日期/标签;
2. 在 `.post-fulls` 里复制一个 `<article>`,`id` 用 `post-full-N`;
3. 卡片上 `data-id="N"` 与全文 `id` 对应即可,零其他改动。

标签配色:`.tag.blue / lime / pink / orange / purple` 五种,对应
编程 / 效率 / 设计 / 随笔 / 整活。

## 交互脚本说明

脚本在文件底部,无依赖、无请求、IIFE 包裹,只有弹层、计数器、问候语、年份四处逻辑。
